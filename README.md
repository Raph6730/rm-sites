# RM Sites

Page de présentation de RM Sites (Raphaël Mata) : création de sites internet sur mesure pour les commerces et artisans de Strasbourg et ses alentours.

- `index.html` : la page (accueil, `#tarifs` pour les formules, `#mentions-legales`).
- `fonts/` : polices Cormorant Garamond et Hanken Grotesk hébergées localement (licence SIL OFL).
- Aperçu de travail : non indexé par les moteurs de recherche (`noindex` + `robots.txt`) tant que l'activité n'est pas officiellement lancée.
